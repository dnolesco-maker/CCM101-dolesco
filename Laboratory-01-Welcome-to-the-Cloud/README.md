Laboratory 01: Welcome to the Cloud

Mission Overview
As a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, this onboarding mission establishes a cloud-based Linux workspace, captures foundational system specs, and sets up a version-controlled GitHub portfolio.

Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

Activities Performed
1. Launched an Ubuntu 24.04 environment on KillerCoda and created user `dolesco` with `sudo` access.
2. Executed Linux system inspection commands to log distribution, kernel, CPU, memory, and disk specs.
3. Structured workspace directories (`Documents`, `Notes`, `Reports`, `Screenshots`) and created an `about-me.md` profile.
4. Created a public GitHub repository named `CCM101-dolesco` and structured laboratory directories.
5. Authored documentation (`README.md`, `system-information.md`, `about-me.md`, `reflection.md`).

Linux Commands Used
- `useradd`, `passwd`, `su`: User creation and account management.
- `whoami`, `pwd`, `hostname`: Context and identity verification.
- `cat /etc/os-release`, `uname`, `lscpu`, `free`, `df`: System diagnostics and metric gathering.
- `mkdir`, `cp`, `ls`: Directory structure creation and file manipulation.
- `git`: Version control and repository initialization.

Skills Learned
- Linux user administration and permission management.
- Command-line system auditing and hardware inspection.
- Technical documentation writing in Markdown format.
- Workspace organization and GitHub repository structure management.
