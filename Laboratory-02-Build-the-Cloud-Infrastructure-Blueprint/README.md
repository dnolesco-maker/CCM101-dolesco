## Cloud Infrastructure Components

### Compute Resources

The Linux server's CPU and memory represent compute resources used to process workloads and run applications.

### Storage Resources

The virtual disk, partitions, and mounted filesystems represent storage resources used to store operating system files, applications, and data.

### Networking Resources

The server's network configuration and IP address represent networking resources that allow the cloud environment to communicate with other systems.

### Operating System

The Linux operating system provides the software environment required to manage the server's hardware resources and run applications.

## Linux Commands Executed

The following Linux commands were used during the cloud server investigation in Checkpoint 2:

| Command | Purpose |
|---|---|
| `cat /etc/os-release` | Identified the operating system, version, and codename. |
| `uname -r` | Identified the Linux kernel version. |
| `lscpu` | Identified CPU architecture, CPU model, CPU count, cores, hypervisor, and virtualization information. |
| `free -h` | Identified RAM and swap memory. |
| `lsblk` | Identified virtual disks, partitions, sizes, and mount points. |
| `df -hT` | Identified filesystem types, disk usage, available space, and mounted filesystems. |
| `hostname` | Identified the server hostname. |
| `hostname -I` | Identified the IP addresses assigned to the environment. |

## Challenges Encountered

One challenge was understanding the information returned by different Linux commands and determining which details were relevant to the cloud infrastructure assessment. Another challenge was comparing equivalent services between AWS, Microsoft Azure, and Google Cloud Platform because each provider uses different service names. Organizing the findings into clear Markdown documentation and maintaining the required GitHub repository structure also required careful attention.
