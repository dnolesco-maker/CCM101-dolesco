# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of cloud services that organizations can use to build, deploy, store, and manage applications and data without having to maintain all of the physical infrastructure themselves. AWS supports different types of organizations, including startups, enterprises, government agencies, and other institutions.

## Global Infrastructure

AWS operates a global cloud infrastructure made up of Regions and Availability Zones. An AWS Region is a separate geographic area, while Availability Zones are isolated locations within a Region. Each AWS Region has multiple Availability Zones that are connected through high-bandwidth and low-latency networks. This infrastructure allows organizations to deploy applications in different geographic locations and design systems for higher availability and fault tolerance.

AWS also provides other infrastructure options such as Local Zones and Wavelength Zones for workloads that need resources closer to users or specific network locations.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS cloud services. Through the console, users can work with services, manage resources, monitor usage, manage users, view account information, and access billing information. It provides a central interface for managing AWS resources without needing to use only command-line tools.

## Four (4) Core Services

1. **Amazon EC2** – Amazon Elastic Compute Cloud (EC2) provides resizable computing capacity through virtual servers in the AWS Cloud. It can be used to run applications, websites, and other workloads.

2. **Amazon S3** – Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve different types of data. It can be used for websites, mobile applications, backups, archives, data lakes, and enterprise applications.

3. **Amazon RDS** – Amazon Relational Database Service (RDS) is a managed relational database service. It helps organizations set up, operate, and scale databases while AWS handles common database management tasks such as backups, patching, and provisioning.

4. **AWS Lambda** – AWS Lambda is a serverless computing service that allows users to run code without managing servers. It can automatically scale according to workload and is useful for event-driven applications and application backends.

## Three (3) Advantages

1. **Wide range of services** – AWS provides many different cloud services for computing, storage, databases, networking, security, analytics, and other workloads.

2. **Global infrastructure** – AWS has a large worldwide infrastructure with multiple Regions and Availability Zones, allowing organizations to deploy applications closer to their users and design highly available systems.

3. **Scalability and flexibility** – AWS allows organizations to increase or decrease resources according to their workload. Services such as EC2 and Lambda provide different ways to scale applications based on their requirements.

## Typical Enterprise Use Cases

Enterprises can use AWS for hosting websites and applications, storing and protecting large amounts of data, running databases, and supporting business applications. AWS can also be used for backup and disaster recovery, data analytics, machine learning, and application development. Organizations can select different AWS services depending on their technical requirements, workload, security needs, and business goals.
