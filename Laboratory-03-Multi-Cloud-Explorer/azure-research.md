# Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services that organizations can use to build, deploy, manage, and scale applications and IT infrastructure. Azure supports services for computing, storage, databases, networking, security, artificial intelligence, and other workloads.

## Global Infrastructure

Azure operates through a global infrastructure made up of geographic regions and availability zones. An Azure region is a geographic area containing a set of datacenters. Many Azure regions provide availability zones, which are physically separate groups of datacenters with independent power, cooling, and networking.

Azure also uses region pairs for some regions. Region pairs can support certain disaster recovery and service replication strategies. Organizations can choose regions based on factors such as service availability, latency, data residency, and reliability requirements.

## Cloud Management Console

The Azure portal is a web-based management interface used to manage Azure resources and services. Through the portal, users can create and manage resources, monitor their cloud environment, configure services, and access different Azure tools and features from a central interface.

## Four (4) Core Services

1. **Azure Virtual Machines** – Azure Virtual Machines provide virtualized computing resources that can be used to run applications and workloads in the cloud.

2. **Azure Blob Storage** – Azure Blob Storage is an object storage service designed to store large amounts of unstructured data such as documents, images, videos, backups, and other files.

3. **Azure SQL Database** – Azure SQL Database is a managed relational database service based on the Microsoft SQL Server database engine. It allows organizations to use a relational database without managing all of the underlying infrastructure themselves.

4. **Microsoft Entra ID** – Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage identities and control access to applications and resources.

## Three (3) Advantages

1. **Microsoft integration** – Azure integrates closely with Microsoft technologies and services, making it useful for organizations that already use products such as Windows Server, Microsoft 365, and other Microsoft technologies.

2. **Global infrastructure** – Azure provides regions and availability zones in many geographic locations, allowing organizations to deploy workloads according to their location, performance, reliability, and data residency requirements.

3. **Wide range of services** – Azure provides services covering areas such as computing, storage, databases, networking, security, artificial intelligence, containers, and application development.

## Typical Enterprise Use Cases

Enterprises can use Azure to host applications and virtual machines, store business data, run databases, manage identities, and support enterprise IT environments. Azure is also commonly useful for organizations that already rely on Microsoft technologies and want to connect or migrate existing systems to cloud services. Other uses include artificial intelligence, analytics, application development, backup, disaster recovery, and hybrid cloud environments.
