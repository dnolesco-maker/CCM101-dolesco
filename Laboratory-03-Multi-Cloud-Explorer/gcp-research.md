# GCP Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform developed by Google. It provides cloud services that organizations can use to build, deploy, manage, and scale applications and infrastructure. GCP offers services for computing, storage, databases, networking, artificial intelligence, data analytics, and other cloud workloads.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of regions and zones. A region is a geographic area where Google Cloud resources can be deployed, while zones are isolated locations within a region. Using multiple zones can help organizations design applications with higher availability and resilience.

Google Cloud also provides a global network that connects its regions and services. Organizations can select locations based on factors such as latency, service availability, data residency, and application requirements.

## Cloud Management Console

The Google Cloud Console is a web-based management interface used to manage Google Cloud resources and services. Users can create and configure resources, monitor their cloud environment, manage projects, view usage, and access different Google Cloud services through the console.

## Four (4) Core Services

1. **Compute Engine** – Compute Engine provides virtual machines that can be used to run applications and workloads in Google Cloud.

2. **Cloud Storage** – Cloud Storage is an object storage service used to store and retrieve data such as files, backups, media, and other unstructured data.

3. **Cloud SQL** – Cloud SQL is a fully managed relational database service that supports database engines such as MySQL, PostgreSQL, and SQL Server.

4. **Google Kubernetes Engine (GKE)** – Google Kubernetes Engine is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

## Three (3) Advantages

1. **Global network infrastructure** – Google Cloud uses Google's global infrastructure and network to connect cloud resources and services across different geographic locations.

2. **Scalability** – GCP provides cloud resources that can be scaled according to application and workload requirements. Organizations can adjust their resources as their needs change.

3. **Wide range of cloud services** – Google Cloud provides services for computing, storage, databases, networking, containers, artificial intelligence, analytics, and application development.

## Typical Enterprise Use Cases

Enterprises can use Google Cloud to host applications and virtual machines, store and process business data, run databases, and deploy containerized applications. GCP can also be used for data analytics, artificial intelligence, machine learning, application development, backup, and other enterprise workloads. Organizations can select Google Cloud services based on their technical requirements, performance needs, security requirements, and business goals.
