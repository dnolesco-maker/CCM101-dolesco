# Mission Reflection

AWS impressed me the most because it offers a broad range of cloud services and has global infrastructure that can support different types of workloads. During this activity, I learned about services such as Amazon EC2, Amazon S3, Amazon RDS, and AWS Lambda. I also found AWS suitable for different scenarios, including startups and global e-commerce companies.

AWS, Azure, and GCP have many similarities because they are all major public cloud platforms that provide services for computing, storage, databases, networking, and identity management. They also provide virtual machine services, object storage, and Kubernetes-related services. These similarities allow organizations to choose between providers based on their specific requirements instead of only the basic cloud capabilities.

Business requirements have an important influence on cloud platform selection because different organizations have different goals, existing technologies, budgets, and workloads. For example, a university using Microsoft technologies may benefit more from Azure, while an AI research company may prefer GCP for AI and machine learning. A startup with a limited budget and expected rapid growth may choose a platform that provides flexible and scalable services.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I learned that I need to analyze the client's situation and match its requirements with appropriate cloud services. The Linux investigation in KillerCoda also helped me understand how an existing server environment can relate to cloud virtual machine services such as Amazon EC2, Azure Virtual Machines, and Compute Engine.

My GitHub Cloud Computing Portfolio improved because I added a complete multi-cloud laboratory with research documents, comparison tables, client recommendations, a decision matrix, and Linux investigation evidence. This mission also helped me organize my technical work using Markdown and screenshots.
