# System Baseline Report

## Host System Resources

The following values were collected from the KillerCoda Ubuntu Playground using Linux command-line tools.

- **Total RAM:** 1.9 GiB
- **Used RAM:** 413 MiB
- **Free RAM:** 1.1 GiB
- **Available RAM:** 1.5 GiB
- **Total Storage Capacity of Root (/) Filesystem:** 19 GB
- **Used Storage:** 5.5 GB
- **Available Storage:** 13 GB
- **Disk Usage:** 30%

## CPU and Running Processes

The `top` command was used to observe active running processes and CPU activity. The task manager was monitored for at least five seconds before exiting.

## Importance of Checking Disk Space

Checking disk space before a massive traffic surge is critical because the server needs sufficient storage for application logs, temporary files, and other data generated while handling requests. Insufficient disk space can cause application errors and affect system performance.
