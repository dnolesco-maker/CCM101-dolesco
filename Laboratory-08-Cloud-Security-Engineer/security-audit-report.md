# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their assigned tasks. It is important in cloud environments because limiting access helps prevent unauthorized activities and reduces the risk of accidental or intentional damage.

## 2. Attack Surface

The attack surface of a virtual machine refers to all the points where an attacker could try to gain access or exploit a weakness. Examples include open network ports, exposed services, and insecure configurations, so reducing unnecessary access points helps improve server security.

## 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a specific rule allows it. This is safer than trying to block individual attackers because unknown or unauthorized connections are denied by default, reducing the number of ways an attacker can reach the server.
