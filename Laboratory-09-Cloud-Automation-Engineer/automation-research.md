# Automation Research: The Language of Automation

## 1. Bash Script

A Bash script is a text file containing commands that the Bash shell executes in sequence to perform tasks automatically. The `#!/bin/bash` line, called a shebang, tells the system to use Bash to interpret the script.

## 2. Variables

Variables store values, such as folder paths, that a script can reuse in different commands. For example, using `$BACKUP_DIR` makes it easier to change the backup location in one place instead of editing every command that uses the same path.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script at specified times or intervals. It is useful in cloud operations because it can automate recurring tasks, such as backups, without requiring someone to run them manually each time.
