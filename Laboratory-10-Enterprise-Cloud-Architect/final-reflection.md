# Final Reflection: My Journey from Mission 1 to Mission 10

Progressing from Mission 1 to Mission 10 in Cloud Computing gave me a clear, practical understanding of how modern infrastructure works behind the scenes. Starting out as a Junior Trainee focused on basic Linux commands and core cloud concepts, each mission built on the last—moving me from running simple terminal commands to architecting full environments.

Across the mid-level missions, I explored the real-world trade-offs between major cloud service providers (AWS, Microsoft Azure, and Google Cloud) and saw firsthand how containerization differs from traditional virtualization. Getting hands-on with Docker, Docker Compose, and persistent storage management clarified how isolated services communicate, share volumes, and run together cleanly in a multi-tier setup.

Beyond deployment, the security and operations missions underscored that spinning up a server is only half the work. Hardening firewalls, managing access permissions, monitoring system resources, and writing Bash automation scripts showed me how to keep infrastructure secure and resilient. Seeing how automated scripts and scheduled backups eliminate manual overhead and prevent data loss was one of my biggest takeaways.

For my final mission as an Enterprise Cloud Architect, I pulled everything together to design and deploy a complete multi-tier cloud stack using VirtualBox, Ubuntu Server, and Docker with persistent storage. Troubleshooting configuration conflicts on my own, validating the deployment, and documenting the entire architecture tested everything I had practiced throughout the course.

Ultimately, Missions 1 through 10 shifted my perspective: cloud computing is not just about getting an application online—it is about deliberate planning, security hardening, continuous monitoring, and clear documentation. Every broken container and permission error along the way sharpened my debugging skills. As a BSIT student, this practical foundation in Linux, container orchestration, and infrastructure administration gives me real confidence heading into my IT career.
