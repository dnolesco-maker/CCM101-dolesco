## 📖 Overview

Welcome to my official **Cloud Computing Portfolio** for **CCM101**. This repository documents my hands-on progression across ten structured laboratory missions—covering Linux system administration, multi-cloud architecture, Docker container orchestration, UFW firewall hardening, Bash automation, and full multi-tier enterprise deployment.

Each mission directory contains configuration files, shell scripts, architectural documentation, system logs, and technical reflections.
